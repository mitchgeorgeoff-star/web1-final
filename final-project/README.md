# web1-final — Final Project Folder

This folder contains the HTML, CSS, and image assets for the final project submission.

## Structure

- `index.html` — main markup file with semantic sections, navigation, and comments.
- `css/reset.css` — resets browser defaults for consistent styling.
- `css/style.css` — layout and visual styles for the mockup.
- `images/` — asset folder used by the site, matching GitHub Pages requirements.

## Notes

- Images are stored in `final-project/images/` so GitHub Pages can serve them correctly.
- The HTML includes comments describing the structure and how CSS will be used.
- No JavaScript is required for this assignment; the page is built using static HTML and CSS only.

## GitHub Pages

If this repository is published with GitHub Pages from the `main` branch root,
then the live site URL should be:

`https://mitchgeorgeoff-star.github.io/web1-final/final-project/`

If you need the root folder instead of `final-project`, move the contents of `final-project`
into the repository root and update the Pages setting accordingly.
